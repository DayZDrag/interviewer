# Промпты интервьюера

Рабочий текст интервьюера — только `prompts/interviewer.v1.md`; проектные AGENTS, checklist и review не включаются в его runtime-контекст.

[interviewer.original.md](interviewer.original.md) — исходный пользовательский промпт. Координатор сообщил, что сохранил его из сообщения после подготовки полного плана. Автор документов прочитал сохранённый файл; в нём присутствуют показанные обратные слеши, включая `is\_clarification` в примере.

[interviewer.v1.md](interviewer.v1.md) — новая компактная редакция по прямому запросу пользователя, только с IDEA-03/04. Краткость не вызывает давление или обязательные дополнительные уточнения; legacy-план сохраняется. Один вопрос уровня `action` предлагает описать выполнение привычного шага, важного по мнению респондента. Поведенческие тесты ещё не проводились. IDEA-01/02 [отложены](../.obsidian/DEFERRED_ISSUES.md).

## Правила хранения

- Хранить оригинал verbatim: без исправлений орфографии, пунктуации, форматирования, слешей и имён полей. Текст из диалога — основание сверки, пересказ в документации его не заменяет.
- Не заменять источник новой версией. В v1 сокращены повторы, удалены декоративные слеши и примеры профессий; исходник не изменяется (SHA-256 `4eba82a874f0a669e91fcce1cb393928422d0133e2d735505bb5864760090931`).
- Единственный автор v1 — автор промпта/документов; исходник он и reviewer только читают. Git выполняет координатор.
- Не добавлять реальные ответы респондентов, персональные данные, секреты или платные API-вызовы.

## Контракт и ограничения

В исходнике упомянут `agent.io/v1` и внешний файл `interviewer.output.schema.json`. Настоящая схема не предоставлена и не создана. Пример внутри промпта — сохранённый исходный текст с артефактами; он не выдаётся за валидированный JSON, готовую схему или реализованный контракт.

В v1 JSON-пример компактный, с обычным `is_clarification` без артефактного backslash; все исходные поля, оба `rationale` и равенство `is_clarification`/`question.clarification` сохранены. Пример не задаёт правил ID или выставления флагов и не заменяет настоящую схему. Без неё совместимость не подтверждается; это не препятствует текстовой редакции. Алгоритм STOP, новые поля и пропуски уровней не добавлены. Роль из запроса не ограничивается демонстрационными профессиями по прямому указанию пользователя; противоречивый оригинал сохраняется.

Сохранены `asked`/`answers`, внешний `next_level`, четыре вопроса нового интервью (один на уровень), legacy-план, исходная связь с контекстом, первый вопрос о роли и запрет его продуктовых терминов, короткие открытые вопросы без таксономии и наводок, привычная работа и дословные цитаты. Подсказки, примеры и варианты ответа допустимы только по просьбе. [Границы и метод измерения](../docs/PROTOTYPE_SCOPE.md) описаны отдельно: сокращение текста не доказывает качество интервью.

Статус сверки исходника и подготовки проекта отражён в [плане](../.obsidian/PROJECT_CREATION_PLAN.md) и [итоговом чек-листе](../.obsidian/FINAL_VERIFICATION_CHECKLIST.md). Наличие файла само по себе не доказывает его посимвольное равенство сообщению.
