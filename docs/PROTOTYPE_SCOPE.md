# Границы текстовой версии интервьюера

`RUN-2026-11-25-05`, 2026-11-25. Пользователь разрешил [v1](../prompts/interviewer.v1.md) только с IDEA-03/04. Это текст для проверки, без приложения, backend/runtime, новой схемы или вызовов LLM API.

## Изменения и сохранённая основа

- **IDEA-03:** спокойная беседа без оценки, давления, похвалы-терапии и выводов о навыках по краткости или нехватке сведений. Короткий ответ не создаёт обязательного дополнительного уточнения; сохранённый legacy-план не переопределяется.
- **IDEA-04:** один вопрос уровня `action` о том, как человек выполняет привычный содержательный шаг, который сам считает важным. Важность субъективна; нет экзамена, доказанной компетенции и набора «что + почему + инструменты + результат».
- **Без новых усилений IDEA-01/02:** они [отложены пользователем](../.obsidian/DEFERRED_ISSUES.md) до обсуждения обратной связи тестов и нового явного выбора. Исходная связь с предыдущим ответом, когда он позволяет, сохранена.

Сохраняются `asked`/`answers`, внешний `next_level`, `max_questions = 4` с одним вопросом на каждый `role → function → task → action`, legacy-план и запрет повторять вопросы. Вопрос короткий, открытый, об одной теме, понятный без таксономии и без наводок. Подсказки, примеры и варианты ответа допускаются только по просьбе. Первый вопрос — о роли без «дерево», «обоснование», `evidence`, `KPI`. Роль из запроса, привычная работа самого респондента и дословные цитаты для методиста сохранены.

В новой редакции объединены повторы, удалены декоративные слеши и демонстрационные профессии. Противоречие списка ролей в оригинале сохранено; для v1 пользователь прямо указал, что примеры не ограничивают роль. [Исходник](../prompts/interviewer.original.md) не редактируется.

## Контракт и открытые вопросы

JSON `agent.io/v1` сохраняет `question{id,level,text,rationale,clarification}`, верхнеуровневые `rationale` и `is_clarification`, оба кратких `rationale` и равенство флагов. В примере v1 нет артефактного backslash в `is_clarification`. Валидность JSON и сохранение набора полей не означают проверку по настоящей `interviewer.output.schema.json`: она недоступна и не реконструируется. Это ограничение совместимости, а не блокировка текстовой работы.

Открыты завершение, условия clarification/ID и ответ за несколько уровней. Новых STOP, правил ID/флагов, JSON-полей, самостоятельных пропусков и дополнительных вопросов нет. fixed4/legacy — лишь описания поведения, не поля API. Вакансии, научные статьи и проектирование обучения остаются внешним контекстом со слов пользователя, без проектирования архитектуры.
