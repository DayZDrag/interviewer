# Интервьюер

Рабочая папка ИИ-интервьюера для получения первичной ветки деятельности человека и исходных ответов для методиста. Текущий этап — компактный промпт v1: спокойная беседа без давления за краткость и один привычный важный для респондента шаг (IDEA-03/04). Качество поведения ещё предстоит проверить на тестах.

## Известный сценарий

Интервьюер получает историю `asked`/`answers` и внешний `next_level`, задаёт ровно один короткий открытый вопрос о привычной работе. Для нового интервью исходный план содержит четыре вопроса: `role → function → task → action`, по одному на уровень. Ранее начатые интервью продолжаются по сохранённому плану.

В исходном описании указан JSON `agent.io/v1`: объект `question` с полями `id`, `level`, `text`, `rationale`, `clarification`, а также верхнеуровневые `rationale` и `is_clarification`. Настоящий `interviewer.output.schema.json` не предоставлен. Этот перечень не заменяет схему; проверка соответствия ей пока невозможна.

Полученная ветка деятельности ограничена рассказом респондента. Она не является полной моделью профессии, объективным рейтингом важности действий или оценкой наличия навыков. Пользователь упоминал вакансии и научные статьи в более широком контексте проектирования обучения; эти компоненты не входят в данный проект.

## Текущая версия и история подготовки

Создан отдельный v1 с сохранением фиксированного плана, контекста и полей JSON. Убраны повторы, декоративные слеши и демонстрационные профессии; роль по-прежнему берётся из запроса. Новых алгоритмов завершения, ID, clarification-флагов и пропусков нет. Метрики и независимая приёмка текущей редакции фиксируются только по отчётам, старые PASS ниже к ней не относятся.

Проект содержит сохранённый исходник, русскую документацию и правила. Подготовка принята: независимая S1 проверяющего, S2/S3 и полный итоговый цикл координатора завершены с PASS; проверены 17 файлов и 43 локальные ссылки. Результаты отражены в [плане](.obsidian/PROJECT_CREATION_PLAN.md), [проверках безопасности](.obsidian/SECURITY_CHECKLIST.md) и [итоговой проверке](.obsidian/FINAL_VERIFICATION_CHECKLIST.md).

Основной коммит `cec2e497f6f30d6eb746aeca56fdcfb479dbbe10` создан и проверен; Git status после него был чист. Текущие записи результатов войдут в отдельный отчётный коммит координатора.

Приложение, API-схема, backend/runtime и парсеры не создаются; LLM API не вызываются. Рабочая папка — `D:\rabota\interviewer`. Локальность была границей bootstrap; публичная публикация текстового проекта разрешена пользователем, Git выполняет координатор.

Проект опубликован в публичном [репозитории GitHub](https://github.com/DayZDrag/interviewer). По отчёту координатора на 2026-11-25 19:26:48 UTC первый корневой коммит `519182b` с GitHub noreply отправлен `public-main:main`; публичность, равенство HEAD и всех 17 blobs подтверждены, итоговая техническая проверка PASS. Последующие отчётные правки — обычные коммиты в существующей `public-main`. Два старых коммита с личной metadata остаются только в локальной `main`; исторические OID выше сохраняются и не обозначают публичные коммиты.

## Правила работы

Из корня проекта выполнить:

```powershell
& 'D:\projects\NEW_PROJECT_CHEATSHEET\scripts\sync-template-instructions.ps1' -ProjectRoot (Get-Location)
```

После успеха прочитать [AGENTS.md](AGENTS.md), затем [PREFERENCES.md](PREFERENCES.md), применимые проектные документы, [BUGS.md](BUGS.md) и существующий журнал отложенных пунктов. [HANDWRITTEN_IDEAS.md](HANDWRITTEN_IDEAS.md) оставлять пользователю; собственные записи в `BUGS.md` оформлять по правилам AGENTS, не меняя пользовательские. Содержимое `.obsidian/` — основная проектная документация; [журнал изменений](.obsidian/CHANGELOG.md) фиксирует выполненную работу.
